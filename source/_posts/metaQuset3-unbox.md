## 彩色透視與 MR

第一次開啟彩色透視最有趣的地方，是現實房間還看得見，但視窗和虛擬物件可以直接浮在空間裡。它還不到完全忘記自己戴著頭盔的程度，畫面也不能真的取代螢幕，不過要拿東西、找控制器或短暫和旁邊的人說話，已經方便很多。
{% asset_img quest_1.webp Quest 3 主選單 %}

## 把 HDMI 畫面放進 Quest 3

我原本以為是讓 Quest 3「輸出 HDMI」，實際測試後方向剛好相反：是把 Switch 之類裝置的 HDMI 畫面，透過 USB 擷取卡送進 Quest 3，再用 Meta Quest HDMI Link 顯示。接法大致是「遊戲機 → HDMI → USB 擷取卡 → Quest 3」。

{% asset_img hdmi_1.webp HDMI 擷取卡連接測試 %}
{% asset_img hdmi_2.webp Quest 3 顯示 switch 的 HDMI 畫面 %}
{% asset_img hdmi_3.webp 在 Quest 3 裡遊玩薩爾達傳說王國之淚 %}

這樣可以把遊戲畫面放到虛擬空間，視窗大小和位置也能自己調整。它很適合拿來實驗，但畫質和延遲仍然會受到擷取卡影響；如果要玩很吃反應速度的遊戲，還是得先看看手上的設備能不能接受。

## 使用心得

Quest 3 對我來說不只是遊戲機，比較像一台可以在 VR、MR、電腦螢幕和外部影像之間切換的實驗裝置。它能玩的東西很多，但重量、續航、網路品質和暈動症都會影響使用時間。二手入手降低了嘗試的門檻，也讓我真的把原本好奇的功能一個個拿來測試，光是這部分就很值得了。
