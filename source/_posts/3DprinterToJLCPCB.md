## 前言

平常少量模型我會直接用自己的 3D 列印機製作，不過如果遇到要印大量模型或要研磨表面，自己處理不一定比較划算。這次便想測試看看，把模型交給 JLCPCB 的 3D 列印服務，成品品質、價格與等待時間是否適合我的需求。

測試的模型材料分別選了透明的 8001 Resin 與白色的 9000R Resin，也可以順便比較兩種樹脂做出來的感覺。

## 下訂

下訂前先把模型輸出成網站接受的 3D 格式，再上傳檔案。系統辨識尺寸後，可以選擇列印技術、樹脂材料、表面處理、數量等選項，頁面也會即時計算製作費用。

送出前我會再確認一次模型單位和成品尺寸，尤其是孔洞、卡榫、薄壁與兩個零件要互相組合的位置。外包雖然省下自己顧機器的時間，但如果尺寸設定錯誤，收到成品後才發現就只能重新下單。

{% asset_img JLCPCB_2.webp 上傳 %}

這張訂單截圖是我當次測試的報價，不代表現在的固定價格。模型體積、材料、數量與表面處理都會影響金額，結帳時也要把運費和可能產生的其他費用一起算進去。

{% asset_img JLCPCB_1.webp 製作金額 %}

## 成品

先看透明的 8001 Resin。我拿它做一個透明的手電筒，透明的程度出乎意外的好，感覺成品已經可以接近市售的商品了。而且因為是使用 SLA ，所以沒有像是 3D 打印那樣的層紋。

{% asset_img 8001Resin.webp 透明的 8001 Resin %}

白色 9000R Resin 的表面稍微有點磨砂的感覺，而且相同的東西，成本是 8000R 的 1/4 而已，所以很適合快速打樣品確認。

{% asset_img 9000RResin.webp 白色的 9000R Resin 與透明的對比 %}

球體是另一個很直接的測試。這種連續曲面用 FDM 列印時容易看出每一層的階梯感，樹脂成品摸起來和看起來都平順不少。

{% asset_img 9000rResinBall.webp 用 9000R 列印的球 %}

地球和底座則同時測試曲面、表面細節與組裝。外觀看起來不錯，不過如果模型包含卡榫或套合結構，設計時還是要預留公差，不能期待兩個同尺寸的面印出來就一定能剛好裝上。

{% asset_img 9000rResinEarth.webp 用 9000R 列印的地球與底座 %}

## 值不值得外包？

這次收到的樹脂成品，在曲面和平整度上都比我自己的 FDM 機器更適合展示。外包也不用自己處理樹脂、支撐和後續清潔，確實省下不少時間。

不過單看頁面上的製作費很便宜，不代表整張訂單一定便宜。數量太少時，運費占比會很高；如果模型仍在反覆修改，每次都要重新下單和等待，也不如在家直接印一版來得快。

我的結論是：初期打樣和尺寸測試仍然適合自己用 FDM 完成；設計確定後，如果需要樹脂的表面品質、透明材料等特殊材質，或想一次製作多件，再交給外部服務會比較合理。
