這次來新北市美術館，主要是為了看托馬斯・薩拉切諾（Tomás Saraceno）的《共織宇宙》。這是他在臺灣的首次大型個展，展場裡可以看到蜘蛛網、線、光、影像和聲音等不同形式的作品。

{% asset_img new-taipei-art-museum-01.webp 倪祥，〈準時下班〉 %}

## 共織宇宙

### 〈關注之網〉

最先注意到的是幾乎佔滿玻璃箱的網。近看是蜘蛛網，退遠一點又有點像星圖、軌道，或某種難以理解的結構。每一條線都非常細，但彼此交疊之後，整個作品反而有種重量感。

這些作品是由真實蜘蛛結成的網，不知道需要花多少時間，才能形成這麼完整又複雜的樣子。另外，大部分的玻璃箱都吊掛在空中，除了保護作品，也能從不同角度觀察裡面的細節。

{% asset_img new-taipei-art-museum-11.webp 被燈光照亮的網狀結構 %}
{% asset_img new-taipei-art-museum-12.webp 蜘蛛網交疊形成的細節 %}

### 〈算法・韻律〉

純白的牆面上分布著許多由黑色細線組成的網，撥動不同位置時，空間裡也會傳出不同的聲響。

一開始以為聲音是細線震動後直接發出的，就像琴弦一樣。不過後來觀察細線的尾端，發現那裡似乎裝有震動感應器，感覺應該是偵測到震動後，再透過喇叭播放聲音。

{% asset_img new-taipei-art-museum-03.webp 從不同角度觀看網狀結構 %}
{% asset_img new-taipei-art-museum-04.webp 延伸到展場上方的細線 %}

### 〈大氣世〉

這件作品由來自不同國家的塑膠袋連接而成，看起來就像一顆巨大的氣球。展場中還有一個小入口可以走進作品內部，裡面能看到不同國家的人在袋子上留下的訊息。
