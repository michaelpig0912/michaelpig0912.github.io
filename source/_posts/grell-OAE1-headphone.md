最近入手了 Drop + Grell OAE1。前陣子朋友跟我說這款耳機在 Amazon 上大跳水，問我要不要一起團購。它原本的售價是 349 美元，當時只要 47.59 美元，大約是新臺幣 1,700 元左右，而且還有免運費。價差實在太大，所以就決定買一支回來聽聽看。

{% asset_img grell-oae1-order-total.webp 500 當時下單金額只要 47.59 鎂元 %}

後來價格稍微漲回去了一點，七月底在 Amazon 上看到的價格是新臺幣 2,208 元，大約 70 美元。

{% asset_img grell-oae1-amazon-price.webp Amazon 七月底的價格 %}

## 開箱與包裝

外盒先是一層印著耳機圖片的黑色紙套，拿掉之後，裡面才是比較簡單的牛皮紙盒。包裝沒有做得很華麗，不過耳機固定得滿完整的。

{% asset_img grell-oae1-outer-box.webp OAE1 黑色外盒 %}
{% asset_img grell-oae1-inner-box.webp OAE1 內層紙盒 %}

打開之後，耳機和線材直接放在內襯裡。盒內附了一條的 3.5 mm 線材跟6.3 mm 轉接頭，以及一張說明書。

{% asset_img grell-oae1-box-contents.webp OAE1 耳機與盒內配件 %}
{% asset_img grell-oae1-user-instructions.webp OAE1 使用說明書 %}

第一次試聽時只有單邊有聲音，原本還以為買到了機王。後來才發現耳機端的線材可以插拔，而且需要插得比想像中更深。重新把接頭用力插到底之後，兩邊就都有聲音了。

## 特別的單體位置

一般耳機的單體大多直接對著耳朵，OAE1 則把單體放在比較前面的位置，再利用角度讓聲音朝耳朵傳過來。這樣的設計是想模擬喇叭從前方發聲的感覺，讓聲音不會只像是貼著左右兩側的耳朵出現。

## 使用感受與聽的感覺

1. 耳罩是厚實的棉絨材質，戴起來的觸感滿舒服的。不過它真的很厚，應該比較適合在冷氣房或冬天使用，不然戴久了可能很容易流汗。耳機的夾頭力道也比較大，不一定每個人都能習慣，但整體的做工和用料都很扎實。

2. OAE1 跟飛利浦 SHP-9500 比較：

   - 兩款耳機的聲音取向很不一樣。OAE1 的低音比較有存在感，想聽低頻的震撼感時會比 SHP9500 更過癮。不過在人聲的部分，有時會覺得低音稍微蓋過中頻，沒有 SHP9500 那麼明亮；當然，SHP9500 原本就比較擅長呈現人聲。以我的感覺來說，OAE1 比較適合電影配樂、現場錄音，或是編制比較大的古典樂。

   - OAE1 相對比較難推。使用相同音量比較時，它的聲音明顯比 SHP9500 小，需要把音量再開大一點。
   
   - OAE1 的解析度比 SHP9500 好一些，可以聽見更多細節。以 47.59 美元的特價來說，我覺得表現很不錯；但如果回到 349 美元的原價，就可能會不太推薦。

   - 至於前置單體帶來的空間感，我實際聽起來沒有特別明顯，整體還是比較接近一般耳機的感覺。
