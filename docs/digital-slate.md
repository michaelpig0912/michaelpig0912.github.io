# SLATE 數位場記板

入口：`/sideProject/digitalSlate/`，已加入 Butterfly 的「小小測試」選單。原始檔位於 `themes/butterfly/source/sideProject/digitalSlate/`；由 Hexo 原樣輸出，不需額外前端框架、外部字型或 CDN。

## 使用

- 填入片名、捲號、場次、鏡號、Take、導演、攝影、整數 FPS 和備註。捲號會顯示在場號左側。
- 點上方黑白打板條、下方打板按鈕，或在非輸入狀態按空白鍵。打板會閃白、合成短音並保存當下資訊與裝置時間。
- 可設定立即打板、3 秒或 5 秒倒數；取消或切換到背景會取消尚未完成的倒數。
- 自動 +1 開啟時，打板畫面保留 1.1 秒供鏡頭辨識，下一 Take 會清空備註。關閉時可手動維持 Take 編號。
- 在紀錄按「編輯」補寫備註、標記 OK／KEEP／NG 或刪除此筆。CSV 供試算表使用；JSON 可備份及合併匯入，重複 ID 保留目前裝置的版本。匯入只合併拍攝紀錄，不覆寫目前場記板設定。
- 場記板有黑、白、藍、綠、紅五種配色；音效可選經典喀聲、低沉木板聲、電子嗶聲，並可先試聽。配色與音效選擇會保留在裝置上。
- 「專注模式」讓場記板填滿可見畫面，支援的瀏覽器也會請求原生全螢幕；只點黑白打板條操作，不顯示底部打板按鈕，並保留離開控制項。橫向或直向切換時跟隨畫面調整，不保留原本的頁面邊距。未提供全螢幕 API 的瀏覽器會填滿網頁可用區域；從主畫面啟動 PWA 可移除 Safari 網址列。iPad 會另外保留一條不透明的系統狀態列安全區，讓時間與系統圖示的材質效果不會模糊場記板。
- 「保持螢幕恆亮」使用 Screen Wake Lock，若被裝置拒絕會顯示目前狀態。

## 正常、尾板與紀錄管理

- 場記板只有「正常」與「尾板」兩種板別；尾板會旋轉整塊場記板 180°，包括黑白打板條。
- 下方表格可直接修改每筆紀錄的板別，並篩選正常或尾板。修改歷史紀錄不影響目前畫面。
- 「清除全部」會先顯示總筆數與確認視窗，包括被篩選隱藏的紀錄。只刪除拍攝紀錄，保留目前表單與設定。
- 舊版 JSON / localStorage 即使包含機器號碼、檔名或相機參數，仍可匯入；新版會忽略這些已取消的欄位，保留其他拍攝紀錄。
- CSV 與 JSON 匯出所有目前使用的欄位，不受表格篩選影響。

## iPad / PWA

使用 HTTPS 網站，或本機開發的 `localhost` / `127.0.0.1`。iPad Safari 開啟後按「分享 → 加入主畫面」，從主畫面開啟並連線載入一次，確認「可離線使用」。在一般區域網路上用 HTTP IP 預覽不具備 Service Worker 所需的安全環境。

所有必要資源均在 App 自己的目錄內預先快取，Service Worker 的作用範圍也只涵蓋此目錄。三種打板音效由 `sounds.mjs` 合成取樣，經典喀聲模擬短促木板碰撞，並非實體場記板錄音；不需下載音檔或使用麥克風，離線也可切換、試聽及打板。

資料以 `localStorage` 的 `michaelpig.digital-slate.v1` 儲存，僅屬於目前瀏覽器 / 主畫面 App，不跨裝置同步。儲存失敗會保留記憶體中的資料並提示匯出；遇到讀取毀損則保留原始資料、不自動覆寫。每次拍攝後請匯出 JSON，避免網站資料清除或系統回收造成遺失。

時間碼以裝置時鐘和選定的整數 FPS 計算，不提供 SMPTE、LTC、外部校時或丟格時間碼。實體螢幕、喇叭及藍牙的延遲不同，需要精準影音同步時請先實測。

## 開發與驗證

```sh
npm run build
node --test tests/*.test.mjs
python3 -m http.server 4173 --bind 127.0.0.1 --directory public
```

在另一個終端，於已安裝 Playwright 的環境中執行：

```sh
node tests/digital-slate.browser.cjs
```

瀏覽器測試可用 `SLATE_URL` 指向其他預覽位址、`CHROME_EXECUTABLE` 指定 Chrome 執行檔、`SLATE_QA_DIR` 指定截圖與下載結果目錄；預設為 `/tmp/digital-slate-qa`。測試涵蓋音效排程、打板快照、重複點擊、備註修改、保存、匯出匯入、倒數、切換背景、離線重載與打板、平板及手機尺寸、儲存毀損與額度不足。

更新 App 檔案時，請同步遞增 `sw.js` 的 `CACHE_NAME` 版本；新版本就緒後會出現「更新版本」，由使用者在拍攝空檔更新。若有新增資源，也要加入 `ASSETS`，保持完整離線快取。

自動化使用 Chromium 模擬 iPad 尺寸與觸控，不能取代實體 Safari。發布後需在 iPad 上確認音量 / 靜音、加入主畫面、飛航模式重新開啟、螢幕恆亮，以及匯出至「檔案」App。
