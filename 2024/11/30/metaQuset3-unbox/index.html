Meta Quest 3 開箱與使用紀錄｜亂買二手紀錄

發表於2024-11-30|更新於2026-07-29|unbox
|字數總計:978|閱讀時長:3分鐘|閱讀量:

會買 Quest 3，主要是想玩 PC VR，也很好奇彩色透視和 MR 到底能做到什麼程度。最後買的是二手 128GB 版本，還一起收到 KIWI design 的 K4 頭帶。這篇就來記錄開箱、連接電腦、把遊戲機畫面放進 Quest，以及這段時間實際玩過的內容。

二手開箱

Quest 3 本體的外型比我想像中簡潔，正面可以看到幾個感測器和攝影機。比起舊版的 HTC 的 VR 眼鏡來說，真的輕便了許多。因為原廠附的頭戴會造成頭部有一些壓力，所以買了 kiwi 的 K4 頭帶。另外 quest 3 的眼罩很大，基本上戴眼鏡也可以無壓力直接使用的。

彩色透視與 MR

第一次開啟彩色透視最有趣的地方，是現實房間還看得見，但視窗和虛擬物件可以直接浮在空間裡。它還不到完全忘記自己戴著頭盔的程度，畫面也不能真的取代螢幕，不過要拿東西、找控制器或短暫和旁邊的人說話，已經方便很多。

把 HDMI 畫面放進 Quest 3

我原本以為是讓 Quest 3「輸出 HDMI」，實際測試後方向剛好相反：是把 Switch 之類裝置的 HDMI 畫面，透過 USB 擷取卡送進 Quest 3，再用 Meta Quest HDMI Link 顯示。接法大致是「遊戲機 → HDMI → USB 擷取卡 → Quest 3」。

這樣可以把遊戲畫面放到虛擬空間，視窗大小和位置也能自己調整。它很適合拿來實驗，但畫質和延遲仍然會受到擷取卡影響；如果要玩很吃反應速度的遊戲，還是得先看看手上的設備能不能接受。

Virtual Desktop 與 PC VR

另一個常用功能是 Virtual Desktop。除了把電腦桌面搬進 Quest 3，也可以選擇不同的虛擬環境，甚至坐在像電影院一樣的空間裡使用電腦。

真正玩 PC VR 時，無線網路的穩定度會很直接地影響體驗。我最期待的當然是《Half-Life: Alyx》，實際進到遊戲世界後，物件比例、距離感和互動方式都和平面遊戲完全不同。

玩過的遊戲

節奏遊戲《Beat Saber》算是最容易讓別人理解 VR 樂趣的一款，戴上去就知道要揮，身體也會很自然地跟著音樂動。

射擊類我試了《Dead Second》、《空間特戰隊》和《Metro Awakening》。明明人還站在房間裡，視線、瞄準和掩體的動作卻會讓身體真的緊張起來。

運動類則玩了《The Thrill of the Fight 2》和《Eleven Table Tennis》。拳擊真的會累，桌球也會不自覺想去靠那張其實不存在的球桌，而且 eleven table tennis 物理反應真的很真實，跟真的的桌球差不了多少，打起來很有感覺。

其他有趣的體驗

另外有下載星空的《Stellarium》，可以把天空和星體搬到眼前， 可以把一整個星空搬到家裡。

《ねこあつめ》小遊戲會利用房間本身當成場景，收集各種貓咪和貓咪互動。滿足租屋處不能養貓的遺憾 XD。

《candy》則是一款目前還在開發中的應用程式，可以把3D圖匯入，並且做一些拆解跟移動，很適合拿來解釋一些物體的構造。

使用心得

Quest 3 對我來說不只是遊戲機，比較像一台可以在 VR、MR、電腦螢幕和外部影像之間切換的實驗裝置。它能玩的東西很多，但重量、續航、網路品質和暈動症都會影響使用時間。二手入手降低了嘗試的門檻，也讓我真的把原本好奇的功能一個個拿來測試，光是這部分就很值得了。
